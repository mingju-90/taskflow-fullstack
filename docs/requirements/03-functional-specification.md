# TaskFlow 功能需求规格

## 1. 字段基线

以下限制用于统一前端校验、Zod Schema、数据库可写字段和测试数据：

| 字段 | 第一版限制 |
| --- | --- |
| 用户名 | 3 到 20 个字符，全局唯一 |
| 邮箱 | 合法邮箱，最多 254 个字符，全局唯一 |
| 密码 | 8 到 72 个字符 |
| 项目名称 | 去除首尾空格后 1 到 80 个字符 |
| 项目描述 | 0 到 1000 个字符 |
| 任务标题 | 去除首尾空格后 1 到 120 个字符 |
| 任务描述 | 0 到 5000 个字符 |
| 评论内容 | 去除首尾空格后 1 到 2000 个字符 |
| 搜索关键字 | 最多 100 个字符 |
| 截止日期 | ISO 8601 日期或日期时间字符串，可为空 |

## 2. 认证需求

| 编号 | 优先级 | 需求 | 验收条件 |
| --- | --- | --- | --- |
| FR-AUTH-001 | P0 | 访客可以使用用户名、邮箱和密码注册 | 合法输入返回用户公开信息和 Token；密码不进入响应 |
| FR-AUTH-002 | P0 | 用户名和邮箱必须唯一 | 重复注册返回冲突错误，数据库不产生重复记录 |
| FR-AUTH-003 | P0 | 密码必须安全哈希保存 | 数据库中不存在明文密码，登录可通过哈希比较成功 |
| FR-AUTH-004 | P0 | 用户可以使用邮箱和密码登录 | 正确凭据返回 Token；错误邮箱或密码统一返回“邮箱或密码错误” |
| FR-AUTH-005 | P0 | 已登录用户可以获取当前用户信息 | `GET /auth/me` 返回当前用户的 `id`、`username`、`email` 和时间戳 |
| FR-AUTH-006 | P0 | 未登录或 Token 无效时拒绝受保护请求 | 返回 `401 UNAUTHORIZED` 或 `401 TOKEN_EXPIRED` |
| FR-AUTH-007 | P0 | 用户可以在前端退出登录 | 本地 Token 和用户状态被清除，受保护路由不可继续访问 |
| FR-AUTH-008 | P1 | 登录接口需要基础限流 | 60 秒内超过 10 次请求返回 `429 RATE_LIMITED` |

## 3. 项目与成员需求

| 编号 | 优先级 | 需求 | 验收条件 |
| --- | --- | --- | --- |
| FR-PROJ-001 | P0 | 已登录用户可以创建项目 | 项目与当前用户的 `OWNER` 成员关系在同一事务中创建 |
| FR-PROJ-002 | P0 | 用户可以查看自己参与的项目 | 列表只返回当前用户具有成员关系的项目 |
| FR-PROJ-003 | P0 | 项目列表支持关键字、角色筛选和分页 | `keyword`、`role`、`page`、`pageSize` 生效，空参数不报错 |
| FR-PROJ-004 | P0 | 项目成员可以查看项目详情 | 详情包含项目字段、当前用户角色和成员列表 |
| FR-PROJ-005 | P0 | `OWNER` 可以编辑项目名称和描述 | 非 `OWNER` 返回 `403 PROJECT_OWNER_REQUIRED` |
| FR-PROJ-006 | P0 | `OWNER` 可以通过邮箱或用户名添加成员 | 只允许添加已存在的其他用户 |
| FR-PROJ-007 | P0 | 重复成员不能重复加入 | 返回 `409 MEMBER_ALREADY_EXISTS` |
| FR-PROJ-008 | P0 | `OWNER` 可以移除 `MEMBER` | 被移除成员立即失去项目及任务访问权限 |
| FR-PROJ-009 | P0 | `OWNER` 不能被移除 | 返回 `409 OWNER_CANNOT_BE_REMOVED` |
| FR-PROJ-010 | P0 | 第一版不支持成员主动退出和负责人转让 | 不提供对应接口和界面入口 |
| FR-PROJ-011 | P0 | `OWNER` 可以删除项目 | 关联记录按事务删除，附件文件随后尽力清理 |
| FR-PROJ-012 | P1 | 项目列表展示名称、描述、角色和更新时间 | 表格或等价扫描型列表在桌面视口下无重叠 |

## 4. 任务需求

| 编号 | 优先级 | 需求 | 验收条件 |
| --- | --- | --- | --- |
| FR-TASK-001 | P0 | 项目成员可以创建任务 | 任务归属当前项目，创建人来自登录用户 |
| FR-TASK-002 | P0 | 任务状态只能是 `TODO`、`IN_PROGRESS`、`DONE` | 非法值返回 `400 VALIDATION_ERROR` |
| FR-TASK-003 | P0 | 任务优先级只能是 `LOW`、`MEDIUM`、`HIGH` | 非法值返回 `400 VALIDATION_ERROR` |
| FR-TASK-004 | P0 | 任务负责人可以为空 | 空值保存为 `null` |
| FR-TASK-005 | P0 | 任务负责人必须是当前项目成员 | 非成员用户返回 `400 ASSIGNEE_NOT_PROJECT_MEMBER` |
| FR-TASK-006 | P0 | 项目成员可以查看任务列表 | 只返回当前项目的任务 |
| FR-TASK-007 | P0 | 任务列表支持关键字、状态、优先级、负责人和截止时间筛选 | 所有筛选可以组合，结果与数据库条件一致 |
| FR-TASK-008 | P0 | 任务列表支持分页 | 默认 `page=1`、`pageSize=20`，最大 `pageSize=100` |
| FR-TASK-009 | P0 | 项目成员可以查看任务详情 | 返回核心字段、创建人、负责人、评论和附件摘要 |
| FR-TASK-010 | P0 | 项目成员可以编辑任务 | 更新后 `updatedAt` 改变，负责人重新校验 |
| FR-TASK-011 | P0 | 普通成员只能删除自己创建的任务 | 删除他人任务返回 `403 TASK_DELETE_FORBIDDEN` |
| FR-TASK-012 | P0 | `OWNER` 可以删除项目内任意任务 | 删除后关联评论和附件记录一并删除 |
| FR-TASK-013 | P0 | 任务详情展示创建时间、更新时间、创建人和负责人 | 空负责人显示“未分配” |
| FR-TASK-014 | P1 | 任务状态变更在列表中即时可见 | 编辑成功后重新加载列表数据 |

## 5. 评论需求

| 编号 | 优先级 | 需求 | 验收条件 |
| --- | --- | --- | --- |
| FR-COMM-001 | P0 | 项目成员可以查看任务评论 | 默认按创建时间正序返回，使用分页结构 |
| FR-COMM-002 | P0 | 项目成员可以发布评论 | 评论作者为当前用户，内容长度 1 到 2000 |
| FR-COMM-003 | P0 | 评论作者可以删除自己的评论 | 删除成功后列表不再包含该评论 |
| FR-COMM-004 | P0 | 项目 `OWNER` 可以删除项目内任意评论 | 非作者 `OWNER` 删除成功 |
| FR-COMM-005 | P0 | 其他普通成员不能删除评论 | 返回 `403 COMMENT_DELETE_FORBIDDEN` |
| FR-COMM-006 | P1 | 评论显示作者、本地时间、内容和可用的删除操作 | 删除按钮只对有权限用户显示 |

## 6. 附件需求

| 编号 | 优先级 | 需求 | 验收条件 |
| --- | --- | --- | --- |
| FR-ATT-001 | P0 | 项目成员可以为任务上传一个附件 | 上传使用 `multipart/form-data`，字段名为 `file` |
| FR-ATT-002 | P0 | 单文件最大 5 MB | 超出时返回 `400 FILE_TOO_LARGE` |
| FR-ATT-003 | P0 | 只允许 PDF、PNG、JPEG、TXT | 非允许类型返回 `400 FILE_TYPE_NOT_ALLOWED` |
| FR-ATT-004 | P0 | 每个任务最多 20 个附件 | 超出时返回 `400 ATTACHMENT_LIMIT_REACHED` |
| FR-ATT-005 | P0 | 存储文件必须使用随机名称 | 数据库同时保存原始文件名、MIME、大小和存储名 |
| FR-ATT-006 | P0 | 附件不能通过公开静态目录访问 | 未经过鉴权接口无法直接读取上传目录文件 |
| FR-ATT-007 | P0 | 项目成员可以通过受控接口下载附件 | 非成员返回 `403 PROJECT_MEMBER_REQUIRED` |
| FR-ATT-008 | P0 | 上传者、任务创建人和 `OWNER` 可以删除附件 | 其他成员返回 `403 ATTACHMENT_DELETE_FORBIDDEN` |
| FR-ATT-009 | P0 | 删除任务或项目时清理附件文件 | 数据库删除成功；文件清理失败只记录日志 |
| FR-ATT-010 | P1 | 任务详情显示文件名、上传者、大小、时间和下载入口 | 上传或删除后以服务端数据刷新 |

## 7. 看板需求

| 编号 | 优先级 | 需求 | 验收条件 |
| --- | --- | --- | --- |
| FR-DASH-001 | P1 | 看板展示任务总数 | 只统计当前用户可访问项目中的任务 |
| FR-DASH-002 | P1 | 看板展示待处理、进行中、已完成数量 | 三个状态数量之和等于总数与状态分组一致 |
| FR-DASH-003 | P1 | 看板展示逾期任务数量 | `DONE` 任务不计入逾期 |
| FR-DASH-004 | P1 | 看板展示完成进度 | `total === 0` 时进度为 0，否则为 `done / total` |
| FR-DASH-005 | P1 | 看板展示最近更新的 5 个项目 | 点击项目进入项目详情 |

## 8. 全局交互需求

| 编号 | 优先级 | 需求 | 验收条件 |
| --- | --- | --- | --- |
| FR-UX-001 | P0 | 所有数据页面覆盖加载中、空状态和错误重试 | 通过组件测试或端到端测试确认 |
| FR-UX-002 | P0 | 写操作展示成功或失败反馈 | 提交成功后出现消息提示；失败消息来自服务端 |
| FR-UX-003 | P0 | 删除项目、任务和移除成员前需要确认 | 取消时不发送请求 |
| FR-UX-004 | P0 | 表单提交期间防止重复提交 | 提交按钮处于禁用或加载状态 |
| FR-UX-005 | P1 | 页面使用中文文案并保持 Element Plus 视觉体系 | 原型和最终页面均使用同一信息层级 |
